# SETUP

## Prérequis
- Node.js 18.17+ (ou 20+)

## Installation locale
```bash
npm install
npm run dev
```

## Build de production
```bash
npm run build
npm run start
```

## Déploiement
- **Vercel** : import du dépôt Git → déploiement automatique (framework : Next.js).
- Aucune variable d'environnement requise.
